# data/videos/

Input videos (H.264 `.mp4`) are **not stored in git**. Put your own videos here.

The examples in the main README use `Walking.mp4`, `Clapping.mp4` and `Meet1.mp4`; the matching
per-frame person boxes are in `data/annotations/` (`<video name>.txt`), which
`benchmark_detection.py` uses to compute precision / recall / F1.
